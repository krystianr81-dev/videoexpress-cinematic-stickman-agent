# Acceptance checklist

## Reference and originality

- [ ] Observations are separated from inferences; reference lip-sync uncertainty is disclosed.
- [ ] New plot, names, narration, and character identity; no copied footage, soundtrack, or reference transcript.
- [ ] Vertical 9:16 is selected in project and generation controls.
- [ ] All human figures share cream circular heads, thin black limbs, colored torsos, irregular ink contours, and illustrated shading.
- [ ] Painted sets remain detailed and coherent; outputs do not switch into 3D or photography.

## Story, image, and audio

- [ ] Eight beats progress from problem to attempts, intervention, stopped cart, and payoff; no accidental action reset.
- [ ] One standalone Nora master is saved and reused; supporting characters and recurring prop identities remain stable.
- [ ] Each image begins at its planned incoming state and contains required props, contacts, and action space.
- [ ] Cart travel direction, wheel count, empty cart state, brake socket, and wedge remain consistent.
- [ ] Clock shop stays left with its ROUND brass clock above the door; cart travels from upper right downhill left on the established camera side.
- [ ] The only wedge starts on Nora's belt, moves to her hand in scene 4, and stays at the wheel after scene 5; no duplicate remains at belt or doorway.
- [ ] One fallen pin stays on a fixed dusty patch near the cart, not at the shop or attached to a moving wheel; scene 7 indicates the empty socket and that pin.
- [ ] Narration is original, roughly 140–160 words, spoken clearly by one verified available system voice.
- [ ] Narration stays in the speech field; visual prompts contain no spoken lines.
- [ ] Default lip-sync is off; facial acting is not presented as verified speech synchronization.
- [ ] Captions use actual measured speech timing, bold white text, black outline, lower-center placement, and readable safe margins.
- [ ] If 1–2-word phrase-group captions are unavailable, the limitation is stated rather than hidden.

## Execution and completion

- [ ] One UI operator; visible account queue limit respected; no duplicate unknown-status jobs.
- [ ] Image enhancement and references checked for visible resets; valid selections retained.
- [ ] Failed/unusable assets receive bounded corrections; successful assets are preserved.
- [ ] Final clip order and count verified; each clip added once; narration retained.
- [ ] Actual transitions, audio, caption synchronization, and representative style frames reviewed where accessible.
- [ ] Auto Align, if used, is followed by boundary inspection; actual runtime is measured.
- [ ] Saved project verified; completed export exists and opens before being described as finished.
- [ ] Final report states what was completed and any unreviewed audiovisual detail or feature limitation.
- [ ] No credentials, private session data, unrelated changes, purchases, deletion, or unrequested public publishing.
